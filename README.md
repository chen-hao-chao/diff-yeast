# Diffusion Model Generation for Yeast Cells

### Create Conda Environment
```bash=
conda create --name diffy python=3.8
conda activate diffy
```

### Ceder Installation
```
pip install -r requirement_all.txt
```

pip install -r requirements_rest.txt
